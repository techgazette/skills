# canvas-design

The Tech Gazette's Skill of the week for 2026-10-11. Made by Anthropic; linked here, not copied.

## What the skill does

These are instructions for creating design philosophies - aesthetic movements that are then EXPRESSED VISUALLY. Output only .md files, .pdf files, and .png files.

Its own description: "Create beautiful visual art in .png and .pdf documents using design philosophy. You should use this skill when the user asks to create a poster, piece of art, design, or other static piece. Create original visual designs, never copying existing artists' work to avoid copyright violations."

## When to use it

You should use this skill when the user asks to create a poster, piece of art, design, or other static piece.

## How to install it

For Claude Code, as the source's README (https://github.com/anthropics/skills#readme) says:

```text
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
```

"After installing the plugin, you can use the skill by just mentioning it."

Or copy the folder for Claude Code (https://code.claude.com/docs/en/skills):

```text
git clone https://github.com/anthropics/skills
cd skills/skills
mkdir -p ~/.claude/skills
cp -r canvas-design ~/.claude/skills/
```
