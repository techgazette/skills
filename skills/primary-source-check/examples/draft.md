Agent Skills, a format originally developed by Anthropic, is now an open standard.
Under the specification, a skill's name can have up to 64 characters and its
description up to 2,048 characters. The spec recommends keeping SKILL.md under
500 lines and the instructions under 5,000 tokens. Claude Code truncates the
combined description and when_to_use text at 1,536 characters in the skill listing.
